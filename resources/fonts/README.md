# Viewer fonts

- `IBM_VGA_8x16.ttf`: unmodified **PxPlus IBM VGA 8x16**, by VileR,
  from [The Ultimate Oldschool PC Font Pack 2.2](https://int10h.org/oldschool-pc-fonts/).
  License: CC BY-SA 4.0; full text in `LICENSE.TXT`.
  SHA-256: `c99fb740581471c2bd239a200c9f7a6c12f60a7099b0f0af795e405281bc2c5f`.
- `Topaz_a1200.ttf`: unmodified **Topaz a600a1200a4000**, by dMG of
  TrueSchool / Divine Stylers; original Topaz credited to AmigaInc.
  [Upstream source and documentation](https://github.com/rewtnull/amigafonts).
  Released upstream under GPL with the Font Exception; see
  `amigafonts-README.txt` (Legal Stuff). The unmodified raw font source is
  included as `Topaz_a1200.raw`; GPL and exception texts are also included here.
  SHA-256: `da95bfdd6d16ac3602f64ae01699808efede94665fa2a7ac5f33e61641a67e14`.

These bitmap-derived outline fonts are rendered at their native 16-pixel
height with antialiasing disabled. Topaz uses the upstream Amiga aspect ratio.
Unicode fallback glyphs are handled by Pango. Fonts are bundled, never downloaded
at application runtime.
